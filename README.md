# 🛒 Amazon Clone (Mini Project)

This is a **frontend-only clone** of the Amazon homepage created using **HTML** and **CSS**. It replicates the look and layout of the real Amazon landing page to practice web development skills such as responsive design, layout structuring, and styling with CSS.

---

## 📸 Preview

![Amazon Clone Screenshot](./hero_image.jpg)  
*A static homepage design mimicking Amazon's style.*

---

## 🚀 Features

- ✅ Responsive navbar with logo, location, search, sign-in, and cart
- ✅ Hero section with promotional message
- ✅ Product grid with 8 shopping category boxes
- ✅ Footer with structured links and site information
- ✅ Font Awesome icons for better visual appeal

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Font Awesome CDN** for icons
